# LamdaFunction 0.1.0: first release

Wave function collapse for Blender 5.2 LTS. Model a small kit of parts, say which faces may touch, and LamdaFunction fills a mesh with them: every neighbouring pair fits, the boundary can be closed, and the same seed gives the same result on every machine.

## What's in it

- **Kits from collections.** Each module is a collection in a "LamdaFunction Library", modelled in a 1 × 1 × 1 cage. Faces carry connector names with a quarter-turn offset, and the viewport overlay shows each module's cage and connector arrows.
- **Rotations.** Rotational freedom per module (None, X, Y, Z or Full). The compiler generates the distinct rotations and merges those that look identical.
- **Rules.** Connector pairs, plus explicit allowed, disallowed and exclusive rules (`a:+X -> b:-X`).
- **Envelopes.** A box of any size, or any mesh whose vertices are the slots, so Geometry Nodes can generate them.
- **Boundary.** Leave it free, or close it with a named connector such as `0` so nothing pokes out.
- **Slot control.** Weights (`wfc_w:<module>`, `wfc_w:#<tag>`), priorities (`wfc_priority`) and fixed slots (`wfc_fix`), as point attributes you can paint or compute.
- **Solver.** A native Rust solver with propagation, backtracking, several attempts and a seed. It runs in the background with live progress, and Esc cancels it. A pure-Python solver takes over if the native one can't load, and gives bit-identical results.
- **Audit.** Before every solve it lists faces with no rule, rules or connectors naming missing modules, slots nothing fits, and modules that can never be placed.
- **Results as attributes.** `wfc_module`, `wfc_rotation`, `wfc_state`, `wfc_step` and others. The *LamdaFunction Materialise* node group places the modules non-destructively, and *LamdaFunction Inspect* colours slots by state and plays back the collapse order.

**Install:** in Blender 5.2, go to Edit → Preferences → Get Extensions → ⌄ → Install from Disk, and pick the zip for your platform. The sidebar (N) gets a **LamdaFunction** tab. The tutorial's first section walks through this.

## Known limitations

- Modules occupy one cell each. Multi-cell modules are planned.
- Envelopes are box grids. Surfaces (filling a shell that follows a curved quad mesh) are the next phase.
- No growth mode, partial re-solve or seed browser yet.
- Interactive use has been tested on macOS (Apple silicon). Windows and Linux are covered by the automated Blender tests, run headless.
